🐍 Боевой питон

Боевой питон — это динамичный 2D экшен-выживание. Вы играете за боевую змею, для которой размер — это не только показатель здоровья, но и единственный способ дать отпор врагам. Ваша цель: выжить на арене с нарастающей сложностью.

Действие разворачиваются на  минималистичном мире-арене. Лаконичный визуальный стиль (зеленая сетка, яркое цветовое кодирование объектов) выбран специально: здесь нет перегруженного визуального шума, что позволяет полностью сконцентрироваться на тактическом маневрировании и выживании под перекрестным огнем.

🎯 Ключевые механики

Главная особенность игры — длина питона является одновременно и его запасом здоровья, и боекомплектом.

Потребление: Сбор обычных (красных) и редких (золотых) яблок позволяет питону расти и набирать очки.

Стрельба: Нажатие на пробел выпускает снаряд, но отнимает один сегмент хвоста. Игроку необходимо постоянно балансировать между ростом и агрессивной защитой.

Прогрессия: После набора 12 очков игра переходит в бесконечный режим. Каждые следующие 10 очков инициируют новую фазу: увеличивается максимальный лимит врагов на арене и повышается шанс появления золотых яблок.

👾 Бестиарий арены

Помимо прочных каменных укрытий (которые блокируют путь, но могут быть разрушены метким выстрелом), на арене генерируются три типа автономных противников:

Пожиратель (Фиолетовый): Мирный, но опасный конкурент. Целенаправленно ищет и съедает яблоки на карте, лишая игрока ресурсов.

Охотник (Оранжевый): Агрессор. Выслеживает игрока по пятам. При столкновении с телом питона отсекает весь хвост, начиная с места укуса.

Страж (Розовый): Неподвижная снайперская турель. Если питон пересекает её линию видимости, Страж накапливает заряд (визуализируется ярким лазером) и через 1.5 секунды производит выстрел.

🎮 Управление и Интерфейс

Вся навигация в игре осуществляется исключительно клавиатурой:

W, A, S, D / Стрелки — Движение питона / Навигация по меню

ПРОБЕЛ — Выстрел / Подтверждение выбора

ESC — Выход в меню паузы / Возврат к предыдущему экрану

Интерфейс не перегружен: внутри игры работает минималистичный HUD со статистикой (стадия, счет, фраги), а меню и пауза реализованы в виде полупрозрачных оверлеев поверх игрового поля. В настройках доступен полноэкранный режим.

💻 Техническая реализация (Под капотом)

Текущая версия игры — это стабильный MVP. Проект разработан с нуля на языке C# с использованием фреймворка Windows Forms.

Архитектура построена на принципах чистого кода и модульности:

Собственный движок (Game Loop): Сердцем игры является таймер (150 мс), который централизованно обновляет координаты объектов, рассчитывает физику столкновений и вызывает перерисовку графики GDI+.

Разделение логики: Монолитный код формы разбит с помощью модификатора partial class на независимые физические файлы: структуры данных (Модель), управление/отрисовка (Представление) и алгоритмы (Контроллер).

Система состояний (State Machine): Управление интерфейсами реализовано через перечисление GameState, что исключает появление багов с множественными системными окнами.

Продвинутый ИИ: Враги не просто двигаются случайным образом. Для Охотников написан жадный алгоритм обхода препятствий, а для Стражей внедрена математическая трассировка лучей по сетке для реализации "захвата цели".

Плавная графика: Включена двойная буферизация (DoubleBuffered = true), чтобы экран не мерцал при постоянном обновлении кадров.

Мгновенное управление: Настроено прямое считывание клавиатуры, чтобы питон реагировал на нажатия (WASD и Пробел) моментально и без задержек.

Умный полноэкранный режим: Игра умеет подстраиваться под любое разрешение монитора, аккуратно убирая системные рамки окна для полного погружения.

🚀 Как запустить проект

Для запуска игры не требуются сторонние движки.

Убедитесь, что у вас установлена Visual Studio.

Скачайте репозиторий (зеленая кнопка Code -> Download ZIP) и распакуйте архив в удобное место.

Откройте файл решения game.sln в Visual Studio.

Если Visual Studio выдает ошибку при открытии решения, просто откройте файл game.csproj напрямую.

Нажмите F5 или кнопку Пуск (Start) на верхней панели.
